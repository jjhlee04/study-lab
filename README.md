144쪽을 원문과 연결하며 11개 안내·주제 표지를 제외한 133쪽에는 페이지별 개념·보충 예제·단계별 풀이·혼동 주의·문제에서 구분할 기준을 작성했습니다. 반복되는 도표는 같은 예제의 상태 변화·후속 풀이로 표시합니다. 실제 시험 출제 예고를 뜻하지 않습니다. 구문 31개·기초 의미론 22개, 총 53개 채점 문제에 선택지별 이유가 있습니다.

`dist/pl-labs.js`는 입력에 따라 결정적인 상태 목록을 만드는 교육용 모델입니다. 어휘 분석, 정규식 조건 대조, 문법 파생, 입력식 AST/연산, EBNF 경로, 정적·동적 범위, 환경·메모리, 블록·수명, 별칭·복사·해제·가비지, 직접 일치 오버로드 후보 실험을 제공합니다. 이전·다음·자동 재생·초기화·입력 변경·예측/결과 비교·도표 확대를 구현했습니다. 예측 오답은 교재의 같은 과목 오답 복습에 저장되며 정답을 다시 맞히면 빠집니다. 범위/메모리 그래프는 실제 컴파일·운영체제 메모리 실행이 아닙니다. 그래프의 해제된 위치 연결은 유효하지 않은 접근을 설명하기 위한 표시입니다.

원문 이미지는 수정하지 않았습니다. 자료 검토에서는 원문·직접 계산/대조·외부 근거 확인·강의 확인 필요를 구분합니다. 외부 확인 범위는 Python 어휘 분석 공식 문서, Java SE 25 대입 명세, C11 위원회 초안의 객체 수명·초기화 규정입니다. 최신 C++ 전체나 강의의 모든 주장을 검증한 것은 아닙니다. C11 초안을 최신 C 표준이라고 표시하지 않습니다.

새 교재의 마지막 위치와 진도를 브라우저에 저장하며 각 페이지에서 중간/기말 범위 포함 여부 또는 미지정을 표시합니다. 시험 범위는 사용자가 설정한 값만 사용합니다. 개인 브라우저 설정은 다른 기기로 동기화되지 않습니다. 내보내기에는 PDF가 포함되지 않습니다.

남은 모델 한계: scanner는 완전한 C lexer가 아니며, AST는 정수·+·*·괄호로 제한됩니다. 동적 범위는 C 코드의 실제 의미가 아닌 비교 가정입니다. 블록의 바이트 정렬과 물리 주소는 재현하지 않습니다. 힙 복사는 단일 정수 객체이며 완전한 언어별 deep copy나 GC를 구현하지 않습니다. 오버로드 실험은 직접 일치 후보를 보여 주며 C++/Java/Ada 변환 순위 전체를 실행하지 않습니다. 실험의 예측 문항은 현재 모델 상태에 대한 문항입니다.

## 사이드바 접기와 손필기

화면 아래 도구 막대에서 학년/목차 창을 접고 펼칩니다. PC에서 접힘 상태는 브라우저에 기억하며 본문 폭이 넓어집니다. 모바일에서는 기존 학년/목차 패널을 열고 닫습니다.

펜은 본문 위에 고정된 남색 선으로 필기합니다. 지우개는 닿은 한 획을 삭제합니다. 이동 모드는 필기 레이어가 입력을 가로채지 않아 원래 버튼·링크·스크롤·텍스트 선택을 사용할 수 있습니다. Escape도 이동 모드로 전환합니다. 펜/지우개 모드에서 본문 터치는 필기 입력이며 스크롤하려면 이동을 선택합니다. 마우스·터치·펜 포인터를 지원하는 Pointer Events로 처리합니다.

`study-handwriting-v1`에 과목/챕터/페이지별 선을 브라우저 localStorage에 저장합니다. 유닉스는 페이지와 학습 탭별로 분리합니다. 레이아웃 크기가 바뀌면 본문 구획의 상대 좌표로 다시 그립니다. 기기 간 동기화·PDF 내보내기·압력/색상/굵기 선택·부분 획 지우기 기능은 없습니다. 저장 공간이 부족하면 도구 막대에 저장 실패를 알립니다. 기존 교재 기록 백업에는 손필기가 포함되지 않습니다. 실험 조건이나 본문 구획 내부를 크게 바꾸면 필기와 세부 요소의 위치가 달라질 수 있습니다.

검증: 1440×1000 PC·390×844 터치 모바일의 사이드바 접기/열기, 접힘 상태 복원, 펜 그리기와 새로고침 복원, 페이지별 필기 분리, 학습 완료에 따른 화면 재생성 후 복원, 본문 폭 변경 후 재배치, 지우개와 삭제 저장, 이동 모드의 클릭/터치 스크롤, 기존 유닉스 실험 버튼을 확인했습니다. 실행 오류와 페이지 가로 넘침 없음. 실제 물리 스타일러스의 압력·팜리젝션은 검증하지 않았습니다.

### 필기 설정·확대·녹음 확장

도구 막대의 설정에서 손가락 필기 허용을 켜거나 끕니다. 꺼도 브라우저의 pen 입력은 유지하며 손가락은 본문 이동에 사용합니다. 이동 모드에서는 펜도 그리지 않습니다. 지우개는 같은 누름을 100ms 이상 유지한 뒤부터 닿은 한 획을 지우고 그보다 짧은 탭은 무시합니다.

본문 확대/축소는 75~200% 버튼으로 제공하며 100% 초기화가 있습니다. 필기 좌표는 확대 배율에 맞게 변환합니다. 확대 본문의 가로 이동은 내부 스크롤 영역에서 하므로 페이지 전체가 가로로 넘치지 않습니다. 도구 막대는 네 모서리·네 변 중앙·화면 중앙의 9개 고정 위치만 선택하며 드래그 이동은 없습니다. 숨기기 후 도구 표시 버튼으로 복원합니다. 설정은 `study-notebook-options-v1`에 저장합니다.

Apple Pencil 몸통 두 번 탭 자동 전환은 구현하지 않았습니다. 일반 웹페이지에서 해당 몸통 동작을 받는 지원 경로를 확인하지 못했으며 UIKit의 UIPencilInteraction은 네이티브 앱 API입니다. 화면 두 번 탭을 몸통 동작으로 대신 처리하지 않습니다. 설정에 이 제한과 Apple 문서 링크를 표시합니다. 실제 iPad/Apple Pencil 기기 검증이 필요합니다.

녹음은 사용자가 시작을 눌렀을 때만 마이크 권한을 요청하고 브라우저 MediaRecorder로 생성합니다. 끝내면 시작한 페이지에 연결해 IndexedDB `study-audio-v1`의 clips에 저장합니다. 녹음 중에는 설정을 닫아도 표시·종료 버튼이 남습니다. 녹음 파일 등록은 파일당 100MB까지이며 재생·내려받기·삭제·현재/전체 페이지 목록을 제공합니다. 파일은 서버 업로드나 기기 간 동기화 없이 해당 브라우저에 보관합니다. 녹음 종료·저장을 마친 뒤 페이지를 닫아야 하며 탭 종료/모바일 백그라운드에서 저장 성공을 보장하지 않습니다. 실패 시 복구 다운로드 링크를 제공합니다.

추가 검증: 9개 배치와 숨김/복원·새로고침, 125% 확대 상태의 필기/지우기, 35ms 지우개 탭 유지와 140ms 누름 삭제, 실제 WAV 파일 재생 메타데이터, 합성 마이크 입력을 이용한 실제 MediaRecorder 녹음→종료→보관→새로고침→삭제, 페이지별 녹음 목록을 검사했습니다. 390px 터치 환경에서 손가락 필기 끔의 이동과 pen 포인터의 필기 유지, 설정 화면·가로 넘침·실행 오류도 검사했습니다. 실제 사용자의 마이크·iPad Safari 권한·Pencil 하드웨어는 직접 검사하지 않았습니다. 마이크가 제한되는 브라우저에서는 오류를 알리고 파일 등록을 유지합니다.

### 간결한 화면·길게 눌러 도구 이동 (최신 동작)

설정의 사용자 지정 확대/축소와 위치 선택 메뉴를 제거했습니다. 예전 zoom 저장값은 적용하지 않으며 브라우저의 기본 확대를 차단하지 않습니다. 설정은 손가락 필기·도구 숨기기·접힌 도움말만 제공합니다. 녹음은 도구 막대의 별도 마이크 버튼으로 엽니다. 저장/사용법/모델 제한 문구는 도움말 또는 원문 탭으로 모았고 반복 안내를 줄였습니다.

막대의 점 모양 손잡이를 400ms 누르면 9개 도킹 위치가 나타납니다. 끌어서 놓으면 가까운 위치에 붙습니다. 짧게 누르거나 누르기 전에 10px 넘게 이동하면 이동을 시작하지 않습니다. 도구 버튼을 눌러 막대가 움직이는 일은 없으며 키보드 방향키 이동도 제공합니다. 왼쪽·오른쪽 벽면 중앙에서는 세로 막대, 위·아래와 모서리에서는 가로 막대이고 아이콘은 회전시키지 않습니다. Escape·포인터 취소 시 원위치를 유지합니다. 도구 위치와 숨김 상태는 기존 저장 키를 이어 씁니다.

프로그래밍언어론 학습 화면을 설명/실험/문제/원문 탭으로 나누었습니다. 내용은 삭제하지 않고 현재 화면에 필요한 부분만 보입니다. 페이지별 마지막 탭은 `study-reader-views-v1`에 저장합니다. 메모와 편집·백업은 접힌 영역에 있으며 안내 페이지에는 실험·문제 탭을 비활성화합니다. 필기는 보이지 않는 구획의 선을 숨기고 돌아왔을 때 다시 그립니다. 학년 창 버튼은 화면 위쪽에 있습니다.
