# 학습 서재 · 2학년 2학기

한국어 유닉스 프로그래밍 학습 교재. `dist/index.html`을 열면 실행됩니다.

범위: 제공된 w01 29쪽, w02 75쪽, w06 73쪽. 별도 WSL 과제 PDF 제외.

## 구성

- `dist/data.js`: 177쪽별 해설과 퀴즈 및 원문 추출 텍스트
- `dist/deep-notes.js`: 연관 페이지의 개념을 연결한 상세 해설
- `dist/engine.js`: 9개 결정적 파일 I/O 교육 시뮬레이션
- `dist/app.js`: 탐색, 구조 실험, 채점, 오답 복습, 로컬 기록
- `dist/reviews.js`: 원문·검증 설명·강의 확인 필요 항목 62개
- `dist/pages`: 177쪽 원문 이미지
- `dist/original`: 범위 원본 PDF 세 개
- `dist/fonts`: Pretendard Variable과 라이선스

기본 기능은 빌드·계정·외부 라이브러리·인터넷 없이 실행됩니다. 상세 사용법은 배포 폴더의 사용안내.txt를 참조하세요.

시뮬레이션은 C 컴파일이나 커널 실행이 아닌 명시된 규칙의 모델입니다. 강의 구두 설명을 재현하지 않습니다.

2주차 추가: `dist/w02-labs.js`의 경로·파일 명령·권한·링크·패턴·vi·make 실험과 `dist/w02-reviews.js`의 32개 검토 항목을 포함합니다. 기존 학습 기록 키와 페이지 ID를 유지합니다.

## 학년·학기·과목 서재

첫 화면은 `2학년 2학기`의 다섯 과목입니다. 유닉스 프로그래밍의 177쪽 교재와 기존 페이지 해시 링크·학습 기록 키를 유지합니다. 프로그래밍언어론에는 구문 59쪽과 기초 의미론 85쪽을 추가했습니다. 나머지 세 과목은 자료 등록 대기 상태입니다.

- `dist/library.js`: 학년/학기 탐색, 과목별 공간, 원본 파일 보관, 시험범위, 질문 기록
- `dist/library.css`: 기존 Pretendard·최소15px·흰색/남색/청록 체계의 서재 화면
- `study-library-v1`: 과목 정보·자료 목록·시험범위·질문의 브라우저 저장 키
- `study-library-files-v1`: 추가한 원본 파일의 브라우저 IndexedDB 보관함
- `unix-lab-progress-v1`: 기존 유닉스 학습 기록 키 유지

자료 등록은 원본을 보관하는 기능입니다. 새 해설·퀴즈를 자동 생성하거나 다른 기기와 동기화하지 않습니다. 중간고사/기말고사 범위를 별도로 선택하며, 새 파일을 자동 포함하지 않습니다. 자료를 보관함으로 옮겨도 복원할 수 있습니다.

검증: 로컬 Edge/Playwright, 데스크톱 1440×1000·모바일 390×844. 이전 자료 목록 마이그레이션, 과목 생성, PDF 등록·재열기, 챕터/페이지 수정·재접속, 59/85쪽 탐색, 표지·참고문헌 퀴즈 제외, 채점·오답 필터, 메모 유지, 정규표현식, AST 비교, 기존 유닉스 시뮬레이션 확인. 실행/콘솔 오류 및 모바일 가로 넘침 없음. Browser 플러그인이 없어 설치된 Edge를 사용했습니다. 백업 가져오기의 잘못된 파일은 검증 후 거부하지만 모든 브라우저의 저장공간 제한이나 실제 기기 간 동작은 검증하지 않았습니다.

## 깊이 있는 학습 교재 개정

144쪽을 원문과 연결하며 11개 안내·주제 표지를 제외한 133쪽에는 페이지별 개념·보충 예제·단계별 풀이·혼동 주의·문제에서 구분할 기준을 작성했습니다. 반복되는 도표는 같은 예제의 상태 변화·후속 풀이로 표시합니다. 실제 시험 출제 예고를 뜻하지 않습니다. 구문 31개·기초 의미론 22개, 총 53개 채점 문제에 선택지별 이유가 있습니다.

`dist/pl-labs.js`는 입력에 따라 결정적인 상태 목록을 만드는 교육용 모델입니다. 어휘 분석, 정규식 조건 대조, 문법 파생, 입력식 AST/연산, EBNF 경로, 정적·동적 범위, 환경·메모리, 블록·수명, 별칭·복사·해제·가비지, 직접 일치 오버로드 후보 실험을 제공합니다. 이전·다음·자동 재생·초기화·입력 변경·예측/결과 비교·도표 확대를 구현했습니다. 예측 오답은 교재의 같은 과목 오답 복습에 저장되며 정답을 다시 맞히면 빠집니다. 범위/메모리 그래프는 실제 컴파일·운영체제 메모리 실행이 아닙니다. 그래프의 해제된 위치 연결은 유효하지 않은 접근을 설명하기 위한 표시입니다.

원문 이미지는 수정하지 않았습니다. 자료 검토에서는 원문·직접 계산/대조·외부 근거 확인·강의 확인 필요를 구분합니다. 외부 확인 범위는 Python 어휘 분석 공식 문서, Java SE 25 대입 명세, C11 위원회 초안의 객체 수명·초기화 규정입니다. 최신 C++ 전체나 강의의 모든 주장을 검증한 것은 아닙니다. C11 초안을 최신 C 표준이라고 표시하지 않습니다.

새 교재의 마지막 위치와 진도를 브라우저에 저장하며 각 페이지에서 중간/기말 범위 포함 여부 또는 미지정을 표시합니다. 시험 범위는 사용자가 설정한 값만 사용합니다. 개인 브라우저 설정은 다른 기기로 동기화되지 않습니다. 내보내기에는 PDF가 포함되지 않습니다.

개정 검증: 144쪽 모두 실제 화면 탐색, 133개 상세 풀이 표시, 표지의 문제·실험 제외, AST 23/35/65/49 결과 및 괄호, 잘못된 식 거부, 정규식 반례·빈 문자열, 목록 파생, EBNF 반복, 정적·동적 범위, 공유/복사/댕글링/가비지 결과, 예측 채점→오답→정답 복습, 자동 재생/이전/초기화, 선택지별 이유, 메모/마지막 위치, 시험 범위 페이지 배지, 기존 유닉스 실험을 검사했습니다. 로컬 Edge에서 1440×1000·390×844 화면과 콘솔·가로 넘침을 확인했습니다.

남은 모델 한계: scanner는 완전한 C lexer가 아니며, AST는 정수·+·*·괄호로 제한됩니다. 동적 범위는 C 코드의 실제 의미가 아닌 비교 가정입니다. 블록의 바이트 정렬과 물리 주소는 재현하지 않습니다. 힙 복사는 단일 정수 객체이며 완전한 언어별 deep copy나 GC를 구현하지 않습니다. 오버로드 실험은 직접 일치 후보를 보여 주며 C++/Java/Ada 변환 순위 전체를 실행하지 않습니다. 실험의 예측 문항은 현재 모델 상태에 대한 문항입니다.

로컬 실행: Node 빌드 과정 없이 `dist`를 정적 HTTP 서버로 제공하고 `index.html`에 접속합니다. 서버를 통해 실행해야 원문 파일과 저장 기능을 같은 origin에서 안정적으로 사용할 수 있습니다. `author_course_depth.py`는 배포 데이터에 페이지별 풀이와 문항·검토 근거를 반영하는 편집 소스입니다.
